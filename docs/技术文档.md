# 智融反诈项目技术文档

## 1. 项目概述

智融反诈是一个多端智能反诈辅助系统，支持文本、图片、音频、视频等多模态诈骗风险检测，并提供微信实时消息监听、监护人联动预警、安全报告、反诈知识库等能力。

系统主要由四部分组成：

- Node.js 后端服务
- Vue 3 + Vuetify Web 前端
- uni-app 小程序/移动端
- Python + wxauto 桌面微信自动化模块

## 4. 系统架构

```text
用户输入 / 文件上传 / 微信消息
          ↓
Web 前端 / 小程序端 / wxauto 脚本
          ↓
Node.js Express API
          ↓
AI 模型分析服务
          ↓
风险结果结构化
          ↓
风险事件 / 通知 / 安全报告 / 知识库
```

系统使用后端统一承接分析请求。前端和 wxauto 模块不直接处理 AI 判断，而是调用后端接口，后端负责模型调用、结果归一化、风险等级校准和数据落库。

## 5. 核心模块

### 5.1 后端 API 服务

主要入口：

```text
backend/start-model.js
```

默认端口：

```text
7007
```

主要职责：

- 提供健康检查接口。
- 管理模型配置和模型切换。
- 提供文本、图片、音频、视频分析接口。
- 提供登录、注册、用户更新和注销接口。
- 提供报告、知识库、预警通知接口。
- 提供监护人绑定和解绑接口。

### 5.2 AI 分析模块

后端支持多个模型配置：

- qwen
- deepseek
- gpt
- claude

模型配置通过环境变量读取，主要包括：

```text
DEFAULT_MODEL
QWEN_API_KEY
QWEN_API_URL
QWEN_MODEL
DEEPSEEK_API_KEY
DEEPSEEK_API_URL
DEEPSEEK_MODEL
GPT_API_KEY
GPT_API_URL
GPT_MODEL
CLAUDE_API_KEY
CLAUDE_API_URL
CLAUDE_MODEL
```

AI 返回结果会被统一整理为：

```json
{
  "risk_level": "high",
  "confidence": 0.92,
  "reasons": ["冒充公检法", "要求转账到安全账户"],
  "suggestions": ["不要转账", "拨打官方电话核实"],
  "summary": "该消息存在明显诈骗风险"
}
```

### 5.3 多模态检测

主要接口：

```text
POST /api/analyze/text
POST /api/analyze/image
POST /api/analyze/audio
POST /api/analyze/video
```

处理逻辑：

- 文本：直接提交模型分析。
- 图片：上传图片后由模型识别图片内容与诈骗风险。
- 音频：上传音频后进行语音相关分析。
- 视频：上传视频后使用 ffmpeg 抽帧，再结合模型分析。

后端会校验上传文件类型和大小，降低非法文件上传风险。

### 5.4 用户与角色模块

系统支持两类核心角色：

- 普通用户
- 监护人

用户数据包含：

```text
id
username
password
email
phone
name
userType
role
riskLevel
bio
guardedUserEmail
createdAt
updatedAt
```

当前比赛演示环境中，部分数据以 JSON 文件形式存储。正式部署时建议改为数据库存储，并使用密码哈希。

### 5.5 监护人联动模块

相关接口：

```text
POST /api/guardian/link
POST /api/guardian/unlink
GET  /api/guardian/links
```

主要能力：

- 绑定监护人与被监护人。
- 查询绑定关系列表。
- 解绑监护关系。
- 风险事件发生后支持通知监护人。

监护人机制主要面向老年人、学生等需要辅助判断风险的人群。

### 5.6 风险事件、通知与报告

相关接口：

```text
POST /api/risk/workflow/medium
POST /api/risk/workflow/high
GET  /api/risk/events
GET  /api/notifications
POST /api/reports
GET  /api/reports
GET  /api/reports/:id/download
DELETE /api/reports/:id
```

风险闭环：

```text
检测结果
→ 风险等级判断
→ 生成风险事件
→ 生成通知
→ 保存安全报告
→ 用户/监护人查看
```

### 5.7 知识库模块

相关接口：

```text
GET    /api/knowledge
GET    /api/knowledge/:id
POST   /api/knowledge
PUT    /api/knowledge/:id
DELETE /api/knowledge/:id
POST   /api/knowledge/update
```

知识库内容包括：

- 诈骗类型介绍
- 典型案例
- 防范建议
- 反诈 PDF 手册
- 反诈视频素材

### 5.8 wxauto 微信自动化模块

主要文件：

```text
scripts/wechat_bridge.py
scripts/wechat_alert_demo.py
run-wechat-demo.bat
run-wechat-alert-demo.bat
stop-wechat-auto.bat
```

核心流程：

```text
连接桌面微信
→ 获取新消息
→ 过滤系统消息和自己发送的消息
→ 调用后端 /api/analyze/text
→ 判断风险等级
→ 弹出桌面提醒
→ 向指定微信联系人发送提醒
```

支持命令：

```text
probe    检测微信连接并列出会话
current  打印当前聊天消息
send     发送微信文本消息
watch    监听新消息
loop     监听、分析并发送预警
demo     演示模式
```

注意：

- 需要 Windows 桌面微信已登录。
- 需要 wxauto Python 环境可用。
- 需要后端服务已启动。
- 该方案适合比赛原型演示，正式落地需要考虑平台合规性。

## 10. 安全与隐私建议

当前项目适合比赛演示，但正式部署前建议完成以下加固：

- 删除所有硬编码密钥，统一放入 `.env`。
- 密码使用 bcrypt 等算法哈希存储。
- 使用 HTTPS 保护传输安全。
- 增加 JWT 或 Session 认证。
- 按用户、监护人、管理员进行权限隔离。
- 对手机号、邮箱、聊天内容等敏感数据脱敏。
- 上传文件增加病毒扫描和更严格的类型校验。
- 增加接口限流和日志审计。

## 11. 已知风险

- 部分源码和数据存在中文乱码，建议统一为 UTF-8。
- `backend/server.js` 中存在旧版逻辑和疑似硬编码密钥，应优先清理。
- 当前 JSON 存储适合演示，不适合高并发或多用户正式环境。
- wxauto 依赖桌面微信窗口状态，稳定性受本机环境影响。
- AI 分析依赖外部模型接口，现场演示需准备备用方案。

## 12. 后续优化方向

- 建立真实诈骗案例库，持续优化识别效果。
- 增加规则引擎作为 AI 失败时的兜底。
- 引入用户反馈机制，标记误报和漏报。
- 增加风险趋势统计和可视化大屏。
- 完善监护人端权限与消息推送。
- 使用数据库替代 JSON 文件存储。
- 将 wxauto 原型替换为更合规的消息接入方案。
